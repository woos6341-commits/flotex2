# ملاحظة عزل الجدولة الخارجية

لا تعتمد نسخة FLOTEX EGP المستقلة على `cron-job.org` ولا على عنوان API لمشروع آخر. مهمة العوائد المقصودة تستخدم Manus Heartbeat فقط عبر `POST /api/scheduled/savings-auto-payout`، بتواتر دقيقة واحدة وبعد تحقق هوية المهمة، وبمهلة انتظار خمس دقائق من الاستحقاق.

وجود handler في الشيفرة لا يعني أن المهمة منشورة أو نشطة. لا تُنشأ مهمة فعلية إلا في runtime الإنتاجي للنسخة المستقلة بعد نشر handler واعتماد خطة ادخار نشطة. لا تستخدم زر تشغيل يدوي أو endpoint مباشر لاختبار صرف حقيقي؛ اختبارات الجدولة تجرى محليًا على بيانات اصطناعية.

هذه الوثيقة تحل محل أي إرشادات قديمة عن حساب Cron خارجي أو رابط المشروع المصدر. يُرجع إلى [CRON_SETUP.md](../CRON_SETUP.md) لمسار Manus المعتمد.
